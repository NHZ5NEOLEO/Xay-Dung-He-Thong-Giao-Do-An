Cổng API Truyền Dữ Liệu Thực Đơn Bán Hàng B2B

Đối tác B2B (nhà hàng / chuỗi F&B) có thể tích hợp API trực tiếp với phần mềm POS của quán (iPOS, KiotViet, CukCuk) để tự động đẩy thực đơn, cập nhật giá và đồng bộ trạng thái còn/hết món theo thời gian thực.

// 1. API LẤY THỰC ĐƠN BÁN HÀNG CỦA QUÁN:
GET /api/b2b/thuc-don/?shop_id={{ current_shop.id }}

// 2. API THÊM MỚI / ĐỒNG BỘ MÓN ĂN VÀO THỰC ĐƠN B2B:
POST /api/b2b/thuc-don/cap-nhat/
